# CLAUDE.md

**noisefloor**: MIT library of analog-video glitch effects for text and images, plus a single-page project site (demo, docs, API reference, playground). Author: **digitalemagine**. Repo `github.com/digitalemagine/noisefloor`, npm `noisefloor` (unscoped), site `https://digitalemagine.github.io/noisefloor/` (GitHub Pages).

## Docs

- `docs/DESIGN.md`: invariants, decisions and rationale, positioning and competitors. **Read the Invariants section before changing `src/` or `site/`; they are hard rules.** Read Positioning before writing README, site or release copy.
- `docs/ROADMAP.md`: pending work, in order. The next task is the first unfinished item.

## Layout

- `src/`: the library, strict TypeScript. `index.ts` (exports, version), `types.ts` (public option and interface types), `shared.ts` (helpers, stepped rAF loop, hover binding), `css.ts` (base CSS in scanline, text and image parts, and injection), `scramble.ts`, `glitch.ts`, `ambient.ts`; `auto.ts` (the `noisefloor/auto` entry: `data-nf` attribute auto-init with a MutationObserver) and `auto-iife.ts` (entry of the script-tag bundle with auto-init).
- `tsdown.config.ts`: builds `dist/` (ESM and CJS for `noisefloor` and `noisefloor/auto` with a shared `core` chunk, minified IIFEs `noisefloor.iife.js` and `noisefloor.auto.iife.js` with the `Noisefloor` global, `.d.ts`, source maps; the build script empties `dist/` first); `scripts/build-css.mjs` then writes `dist/style.css` (the `noisefloor/style.css` export) from the `CSS` string in `src/css.ts`.
- `site/index.html`, `site/style.css`, `site/main.js`: the project site (`main.js` is a classic script using the `Noisefloor` global, type-checked through `site/tsconfig.json` and `site/globals.d.ts`). `scripts/build-site.mjs` writes `site/dist/`: inlines the TypeScript sources at the `<!--__SRC__-->` placeholder and copies the page files, `dist/noisefloor.iife.js`, media and fonts. `site/fonts/`: self-hosted Chakra Petch and JetBrains Mono subsets with their OFL licences; the site makes no third-party requests. `site/media/*.webp`: reduced side illustrations, copied to `site/dist/media/` (full-resolution originals there are gitignored; never commit them). `site/media/demo.gif` (README GIF) and `site/media/og.jpg` (Open Graph image) are generated by `scripts/capture.mjs` and committed; `site/favicon.svg`. The page footer version comes from `package.json` (`<!--__VERSION__-->`).
- `test/`: Vitest unit tests in headless Chromium (browser mode, Playwright provider): Ambient scheduling, option merging and validation, CSS injection and `configure()`, Scramble burst selection, lock ranks, `play({ text })` and typing, `finished`, bind triggers (`visible`, `once`), Glitch burst arguments and canvas buffers, `noisefloor/auto` (attribute parsing, triggers, shared Ambient, DOM-driven setup and teardown), and that the README option tables list every option with its current default (`test/readme.test.ts`). Two projects: `dev`, and `production` (source compiled with `process.env.NODE_ENV` = `"production"`) for `test/production.test.ts`. `resetWarnings()` in `src/shared.ts` is a test hook. `test/regressions.test.ts`, present only while `ROADMAP.md` lists known bugs: one `it.fails` test per bug; the suite passes while the bug exists.
- `scripts/smoke.mjs`: Playwright smoke test of the built site (text width stable during scramble, image overlay live and sized to the content box, ambient fires, no page errors), plus a page served with a strict CSP: the injected style is blocked, and `style.css` with `configure({ injectCSS: false })` styles the effects with no violation; a page loading `noisefloor.auto.iife.js` in `<head>` (attribute setup, hover, shared Ambient, elements added later); and the playground: closed by default, toggles that say Open or Close, at 1600 px a side panel that pushes the page, applies settings, keeps the image overlay sized, scrolls the demo into view on Replay demo and closes on Escape, and at 1100 px the controls expanding in the Playground section.
- `scripts/treeshake.mjs`: bundles a single named import of each effect from `dist/noisefloor.js` with esbuild (production) and fails if another effect's class is left in; prints the gzipped sizes.
- `scripts/capture.mjs`: records `site/media/demo.gif` and `site/media/og.jpg` from the built site with Playwright (fake clock, seeded `Math.random`) and ffmpeg. Re-run after visible site or effect changes.
- `scripts/fidelity.mjs`: Playwright check that the image overlay covers the img content box and its base frame matches the real img, across object-fit / object-position / border / padding cases and inside `<picture>`, and that the visible overlay covers a transformed img, including a transform changed while playing.
- `.github/workflows/ci.yml`: on push to `main`, pull requests and manual runs: typecheck, unit tests, build, `check:package`, site build, smoke and fidelity; then, on `main` of this repository, deploys `site/dist` to GitHub Pages.
- `.github/workflows/release.yml`: on a `vX.Y.Z` tag matching `package.json`: the CI checks, `npm stage publish --provenance` (trusted publishing, environment `npm`; the owner approves with 2FA), and a draft GitHub release with that version's `CHANGELOG.md` entry. A manual run ends with `npm pack --dry-run`.

## Commands

```sh
npm run typecheck    # tsc --noEmit (src and test), then site/main.js against the library types
npm test             # Vitest unit tests
npm run build        # dist/
npm run check:package # publint --strict, attw (node16 profile), tree-shaking check (needs dist/)
npm run build:site   # site/dist/ (needs dist/)
npm i && npx playwright install chromium && npm run smoke   # build, build:site, smoke test
npm run fidelity     # build, build:site, image overlay fidelity check
npm run capture      # build, build:site, re-record the README GIF and the Open Graph image (needs ffmpeg)
```

## Working rules

- Release: set the version in `package.json` (`npm version X.Y.Z --no-git-tag-version`), add its `CHANGELOG.md` entry (`## X.Y.Z (date)`), commit, then tag `vX.Y.Z` and push the tag only when the owner says so. `.github/workflows/release.yml` runs the checks, stages the version on npm and creates a draft GitHub release; the owner approves the staged version with 2FA (npmjs.com or `npm stage approve <id> --otp=<code>`) and then publishes the draft.

- Behaviour-preserving changes and fixes go in separate commits.
- Run the unit tests and the smoke test before claiming something works; also the fidelity check when touching image geometry (`src/glitch.ts` layout, transforms or buffers).
- When a roadmap item is done, remove it from `ROADMAP.md`; record any lasting decision in `DESIGN.md`.
- Fixing a known bug makes its `it.fails` test in `test/regressions.test.ts` fail: turn it into a plain `it` (moving it to the matching test file if one fits) in the fix commit. A newly found bug gets an `it.fails` test in `test/regressions.test.ts` (create it if absent; delete it when empty, since Vitest fails on a file without tests) and a `ROADMAP.md` entry.
- Docs describe the current state and pending work only, never how it was reached.

## Owner preferences

Technically precise, direct prose. No filler, no em-dashes, no emoji in docs or commit messages. Expect logical sanity checks and verification before claiming something works.
