noisefloor

Analog-video glitch effects for the web: a per-character text scramble, a canvas image glitch, and a scheduler for ambient micro-glitches. One script, no build step, no dependencies. The menu above and the images below are the effects.

Get started

    

      
    
        
  1. 
          
    Include the script
    
          
    A single file, about 7.5 KB gzipped, with TypeScript types, for Safari 16, Chrome and Edge 107, Firefox 104 and later. It injects its own base CSS, placed first in <head> (or in the shadow root, for elements inside one) so your styles win. Under a Content-Security-Policy that blocks inline styles, load noisefloor/style.css instead and call configure({ injectCSS: false }) before creating instances.
    
          
    npm i noisefloor
import { Scramble, Glitch, Ambient } from 'noisefloor';

// or, without a bundler: one script tag, one global
<script src="https://unpkg.com/noisefloor"></script>
const { Scramble, Glitch, Ambient } = Noisefloor;
    
        
    2. 
        
  2. 
          
    Use the markup you have
    
          
    Effects apply to the elements you already have. Text is split into characters at runtime; images keep their <img> element, which Glitch wraps in a positioned span (or in a parent you mark data-nf-wrap).
    
          
    <nav>
  <a href="#docs"><span class="label">Docs</span></a>
  <a href="#about"><span class="label">About</span></a>
</nav>
<img class="glitch" src="feed.jpg" alt="Camera feed">
    
        
    3. 
        
  3. 
          
    Bind from JavaScript
    
          
    bind() takes any CSS selector, wraps every match and plays on hover or focus of the closest link or button. Add Ambient for random micro-glitches.
    
          
    const labels = Scramble.bind('nav a .label');
const images = Glitch.bind('img.glitch');
new Ambient([...labels, ...images], { rate: 30, amount: 0.25 });
    
        
    4. 
        
  4. 
          
    Or declare it in HTML
    
          
    For static pages and CMS content: import noisefloor/auto once, or load noisefloor.auto.iife.js (the library plus auto-init, about 8.5 KB gzipped) instead of the plain script. Options are attributes; elements added later are set up and removed ones destroyed.
    
          
    <script src="https://unpkg.com/noisefloor/dist/noisefloor.auto.iife.js"></script>

<a href="#docs"><span data-nf="scramble" data-nf-order="center">Docs</span></a>
<img data-nf="glitch" data-nf-rgb-split="6" data-nf-ambient src="feed.jpg" alt="Camera feed">
    
        
    5.

        How it works
      

    

    

      

        
new Scramble(element, options)

        
Per-character text scramble. The element's text (or its data-text) becomes the label; a second instance on the same element replaces the first. Child elements are not kept: <b>, icons and other markup inside the element are replaced by its plain text, so target an element that holds only text. Each user-perceived character is animated on its own, so joined scripts such as Arabic or Devanagari render unjoined. Made for labels and headings, not paragraphs: every character is its own element, restyled on each frame.

        
    
          
  • .play() full scramble; characters lock in order
    • 
          
  • reveal: 'type' types the label in order instead, each character scrambling for trail before it locks; cursor: true adds a block caret at the typing head. The run fits the text into duration; speed types at a fixed number of characters per second instead, so longer labels take longer: { reveal: 'type', speed: 30, cursor: true }
    • 
          
  • .play({ text }) scramble to a new label: the width changes once when it starts, then nothing moves; the accessible label and .text update at once. Reserve the widest label with min-width on the element to avoid even that move.
    • 
          
  • .burst({ amount, count, duration, intensity }) micro-glitch on part of the label; ignored while playing
    • 
          
  • .set(options) update options, safe while playing
    • 
          
  • .finished promise resolved with the instance when the current animation ends (naturally, by finish() or destroy()); already resolved when idle, never rejects: await label.play().finished
    • 
          
  • .finish() jump to rest · .destroy() restore plain text · .running true while animating · .destroyed true after destroy, when the other methods do nothing · .options the current options, read-only (change them with set())
    • 
          
  • Scramble.bind(targets, options, { trigger, host, once }) returns instances. trigger: an event name (default mouseenter, which also plays on focus) or 'visible', when the host scrolls into view (labels already in view play at once); once: true plays on the first trigger only. Typed reveal on scroll: Scramble.bind('h2', { reveal: 'type', cursor: true }, { trigger: 'visible', once: true })
    • 
        

        

          Options 
          

        

      

      

        
new Glitch(img, options)

        
Canvas image glitch over an existing <img>. Wraps it (or its <picture>) in a positioned span, or reuses a parent marked data-nf-wrap; a second instance on the same img replaces the first. Honours object-fit and object-position.

        
    
          
  • .play() · .burst({ amount, duration, intensity }) · .set(options) · .finish() · .finished · .destroy() · .running · .destroyed · .options · .ready true once the image is loaded and measured
    • 
          
  • Glitch.bind(targets, options, { trigger, host, once }) returns instances; same triggers as Scramble.bind
    • 
        

        

          Options 
          

        

      

      

        
new Ambient(targets, options)

        
Fires burst() on a random idle target at random intervals. Accepts any mix of text and image instances and drops destroyed ones; skips while the tab is hidden.

        
    
          
  • .fire() one micro-glitch now · .set(options) · .setTargets(targets) · .start() · .stop() · .destroy() stop for good (targets are not destroyed) · .options
    • 
        

        

          Options 
          

        

      

      

        
configure(options)

        
Library-wide settings. injectCSS: false stops the base stylesheet from being inserted, for pages that load noisefloor/style.css themselves, such as under a Content-Security-Policy without 'unsafe-inline' in style-src. It applies to documents and shadow roots not styled yet, so call it before creating instances.

      

      

        
noisefloor/auto

        
Effects declared in HTML attributes. Importing the module (or loading noisefloor.auto.iife.js, the full library plus auto-init) scans the document when it is ready and watches it: elements added later are set up, removed ones are destroyed, and changing data-nf rebuilds the effect. Other attributes are read once; elements that already have an instance are skipped. Not for markup a framework renders: use the recipes below.

        
    
          
  • data-nf scramble or glitch (an <img> only)
    • 
          
  • data-nf-<option> any effect option, in kebab case (data-nf-rgb-split) or as one word; booleans are true when present and false with "false"; data-nf-palette is a comma-separated list
    • 
          
  • data-nf-trigger as bind()'s trigger, or none · data-nf-once · data-nf-ambient join one shared Ambient
    • 
          
  • scan(root) set up a root the observer does not see, such as a shadow root · start() · stop() destroy every attribute instance · ambient() the shared Ambient: ambient().set({ rate: 12 }). The script-tag bundle exposes them as Noisefloor.auto.
    • 
        

      

      

        
Frameworks

        
React, Vue and Svelte own the nodes they render, while Scramble replaces an element's children and Glitch moves the img into a wrapper. Without care, the next render corrupts the label or throws (React: insertBefore ... is not a child of this node). Three rules keep them apart:

        
  • Render the label once, then change it with play({ text }): the framework never patches the text node Scramble replaced. React: the first value from useState; Vue: v-once; Svelte: untrack.
  • Wrap the img in an element marked data-nf-wrap. Glitch uses it instead of inserting its own wrapper, so the img stays where the framework put it.
  • Create instances after mount and destroy() them on unmount. Options are read at mount; change them later with set().

        
Checked with React 19 (StrictMode), Vue 3.5 and Svelte 5.

        

          React
          
// ScrambleText.jsx
import { useEffect, useRef, useState } from 'react';
import { Scramble } from 'noisefloor';

export function ScrambleText({ text, options, bindOptions }) {
  const ref = useRef(null);
  const inst = useRef(null);
  // Rendered once: Scramble owns the children from then on; later text goes through play().
  const [initial] = useState(text);

  useEffect(() => {
    const [s] = Scramble.bind(ref.current, options, bindOptions);
    inst.current = s;
    return () => s.destroy();
  }, []);

  useEffect(() => {
    const s = inst.current;
    if (s && s.text !== text) s.play({ text });
  }, [text]);

  return <span ref={ref}>{initial}</span>;
}

// GlitchImage.jsx
import { useEffect, useRef } from 'react';
import { Glitch } from 'noisefloor';

export function GlitchImage({ options, bindOptions, ...img }) {
  const ref = useRef(null);

  useEffect(() => {
    const [g] = Glitch.bind(ref.current, options, bindOptions);
    return () => g.destroy();
  }, []);

  // data-nf-wrap: Glitch uses this span instead of moving the img into its own wrapper.
  return (
    <span data-nf-wrap="" style={{ display: 'inline-block' }}>
      <img ref={ref} {...img} />
    </span>
  );
}

        

        

          Vue
          
<!-- ScrambleText.vue -->
<script setup>
import { onBeforeUnmount, onMounted, ref, watch } from 'vue';
import { Scramble } from 'noisefloor';

const props = defineProps({ text: { type: String, required: true }, options: Object, bindOptions: Object });
const el = ref(null);
let s = null;

onMounted(() => { [s] = Scramble.bind(el.value, props.options, props.bindOptions); });
watch(() => props.text, (text) => { if (s) s.play({ text }); });
onBeforeUnmount(() => { if (s) s.destroy(); });
</script>

<template>
  <!-- v-once: Vue renders the first text and never patches it; later text goes through play() -->
  <span ref="el" v-once>{{ text }}</span>
</template>

<!-- GlitchImage.vue -->
<script setup>
import { onBeforeUnmount, onMounted, ref } from 'vue';
import { Glitch } from 'noisefloor';

const props = defineProps({ src: String, alt: String, options: Object, bindOptions: Object });
const img = ref(null);
let g = null;

onMounted(() => { [g] = Glitch.bind(img.value, props.options, props.bindOptions); });
onBeforeUnmount(() => { if (g) g.destroy(); });
</script>

<template>
  <!-- data-nf-wrap: Glitch uses this span instead of moving the img into its own wrapper -->
  <span data-nf-wrap style="display: inline-block"><img ref="img" :src="src" :alt="alt"></span>
</template>

        

        

          Svelte
          
<!-- ScrambleText.svelte -->
<script>
  import { untrack } from 'svelte';
  import { Scramble } from 'noisefloor';

  let { text, options, bindOptions } = $props();
  // Rendered once: Scramble owns the children from then on; later text goes through play().
  const initial = untrack(() => text);

  function scramble(node, text) {
    const [s] = Scramble.bind(node, options, bindOptions);
    return {
      update(next) { s.play({ text: next }); },
      destroy() { s.destroy(); }
    };
  }
</script>

<span use:scramble={text}>{initial}</span>

<!-- GlitchImage.svelte -->
<script>
  import { Glitch } from 'noisefloor';

  let { options, bindOptions, ...img } = $props();

  function glitch(node) {
    const [g] = Glitch.bind(node, options, bindOptions);
    return { destroy() { g.destroy(); } };
  }
</script>

<!-- data-nf-wrap: Glitch uses this span instead of moving the img into its own wrapper -->
<span data-nf-wrap style="display: inline-block"><img use:glitch {...img} /></span>

        

      

      

        
How it works

        
Text geometry is locked per character. Each glyph animates inside a cell sized by an invisible copy of the real character, so scrambled glyphs, proportional fonts and fallback fonts cannot change layout.

        
Only compositor-friendly properties move. JS swaps glyphs and writes CSS custom properties at a stepped frame rate; CSS renders jitter and skew as transform, flicker as opacity, RGB split and glow as text-shadow, and the phosphor decay as transitions.

        
Images never touch layout. The <img> keeps its place, alt text and click target. A canvas laid over it appears only while glitching. Channels are separated once by compositing and recombined additively, with no pixel reads, so cross-origin images work without CORS headers.

        
Micro-glitches are Poisson-timed. Intervals follow an exponential distribution around the chosen rate, so glitches cluster and pause like real interference.

        
Accessible by construction. Real labels live in visually hidden spans, animated layers are aria-hidden, and prefers-reduced-motion disables playback.
